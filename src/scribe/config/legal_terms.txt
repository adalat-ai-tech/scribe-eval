# Legal Domain Configuration
# Indian legal terminology for ASR error analysis.
# English rules derived from English legal transcripts.
#
# Tagging rules:
# - Anchor words (Section, Order, Rule, Article, case type + No.) are LEGAL;
#   the reference after them is one NUMERAL token: Section | 5(1)(a)
# - Multi-word legal names (Acts, courts, titles, proceedings) are one LEGAL
#   token; a leading state/place name stays LEXICAL: Kerala | High Court
# - (?-i:...) makes one pattern case-sensitive inside this case-insensitive
#   file; used where capitalisation is what marks the legal term
#
# Ordering: when two patterns can start at the same word, the one listed
# FIRST wins (not the longest). Longer families are therefore listed before
# shorter ones, and every English entry is a REGEX: line, since plain literal
# terms are always tried before any REGEX: line. The Malayalam single words
# stay plain literals; they never start where an English pattern does.

# Metadata
@name: legal
@category: LEGAL
@case_sensitive: false
